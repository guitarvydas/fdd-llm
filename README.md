# Five Whys Tool
Code to accompany book "Failure Drive Development"

Build a simple project using PBP (Parts Based Programming)

# Usage
Set the environment variable `OPENAI_API_KEY` to your openai key ($'s)
`./@install` (first time only)
`./@make`

The expected output is several dumps of intermediate text during each loop (in the form of successive questions derived from previous answers), followed by a JSON array [{ "": "..."}] containing a single key/value pair. The key is the empty string `""` and the value is a string generated by the LLM after five cycles through the question/answer loop. You may use a program text editor to make the value string more readable.

The kick-off question is 'is concurrency considered difficult?' contained in the custom make script `./@makec` (which is invoked by `./@make`)

This example uses the OpenAI API via a GoLang library called `Agency`. You need to put a few $'s into the account ($15.00?).

You can probably change this code to use a different AI api. If it's not obvious how, then contact me for free kibitzing.

# Source Code
Use the drawio editor [drawio.com] to read or edit `llm.drawio`.

Use a programming text editor to read the code `counter.py` that implements a counter Part in Python (a small portion of the project).

Read LLM code (if desired) in `./agency/`
